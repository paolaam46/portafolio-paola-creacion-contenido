# Diseño del Proyecto

## Dirección visual
- Estética elegante y moderna
- Paleta suave y profesional
- Tipografía clara y elegante
- Uso de espacios amplios y buen equilibrio visual

## Estructura base
1. Hero principal
2. Sección sobre mí
3. Sección de servicios
4. Sección de portafolio
5. Sección de contacto
6. Pie de página

## Reglas de implementación
- Utilizar HTML semántico y estructura limpia.
- Mantener las clases con metodología BEM.
- Usar nombres en inglés para las clases y secciones.
- No agregar contenido real, textos ficticios, imágenes de prueba ni componentes innecesarios.
- Dejar la plantilla vacía y lista para construir posteriormente.
- No usar estilos inline ni IDs salvo que sean estrictamente necesarios.
- Separar cada sección con comentarios claros en CSS.
- El diseño visual se implementará más adelante en CSS.

## Objetivo del diseño
Transmitir creatividad, confianza y profesionalismo a través de una identidad visual sencilla y atractiva, con una base fácil de mantener y escalar.
